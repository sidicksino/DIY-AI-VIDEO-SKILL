# Luna's locations

The channel is no longer one cottage garden. Every project picks a **build**
location and a luxury **reveal** location from this list. Copy the location text into every prompt word for word, the same way
the Luna description is copied from `luna.md`.

Learned from the Instagram compilations in `references/` (analysed
2026-11-08). Projects are **built** in a work place and **revealed** in a
luxury place.

| Key | Use it for | Prompt text |

## Rules
- **One build location + one reveal location per project.** Never move
  place inside a clip. The reveal is its own clip from its own hero image, so
  the cut hides the change of place.
- **Wider framing works for big builds.** For `villa-lawn`, `empty-house` and
  `driveway`, show Luna standing full-body with the whole build in shot, as in
  the references. Keep the low kneeling framing for small builds.
- **Day → night is a payoff.** For `villa-lawn`, `pool-terrace` and `rooftop`,
  the last frame can be the same shot at dusk with the lights on (the topiary
  reference ends this way).
